## جایگاه پژوهشی

این پروژه برای بررسی پیاده‌سازی dashboard، دریافت داده و اتصال آن به P/S/T قابل استفاده است. ادعاهای مربوط به پیش‌بینی یا دقت باید مستقل بازآزمایی شوند و صرفاً از README نتیجه‌گیری نشود.

## ویژگی‌ها

- موتور P/S/T
- داده‌های EUR/USD از طریق yfinance
- پیش‌بینی بازه‌های کوتاه
- داشبورد تعاملی
- نمایش فازهای شناختی

## نصب و اجرا

```bash
pip install -r requirements.txt
python app.py
```

سپس به `http://127.0.0.1:5000` بروید.
